# @sketch/protocol-client

The product's client: generated by [tool-codegen](../../../rust/crates/tool-codegen/README.md) from the [protocol
crate](../../../rust/crates/protocol/README.md), over a byte-level transport. A product reaches the core only through
it.

## Look at

1. `src/generated/client.ts` (after `make codegen`): each method encodes its request and decodes its result.
2. [`src/transport.ts`](src/transport.ts): frames and request ids. Subscriptions are observables.
3. [`src/sandbox.ts`](src/sandbox.ts): the product's side of the iframe handshake.

## Tests

[`src/transport.test.ts`](src/transport.test.ts): the frame bytes, and the generated client over a loopback transport.
